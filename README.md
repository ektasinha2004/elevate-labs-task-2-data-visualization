## 🌟 PROJECT OVERVIEW

Welcome to **Task 2: Data Visualization and Storytelling**, completed as part of the Elevate Labs Data Analyst Internship tasks.

The goal of this project is to transform a Superstore sales dataset into an interactive Power BI dashboard that communicates business performance through compelling visualizations.

Rather than simply presenting numbers, this project focuses on understanding sales trends, profitability, regional performance, product categories, and customer segments.

### 🎯 Project Objective

- 📊 Build meaningful and interactive data visualizations.
- 💰 Analyze sales, profit, and quantity performance.
- 🌍 Compare business performance across regions.
- 🛍️ Understand category and sub-category trends.
- 📅 Identify changes in performance over time.
- 💡 Present findings through data storytelling.
