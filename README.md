# Elevate Labs Task 2 – Data Visualization and Storytelling

## Objective
Create visualizations that communicate meaningful business insights using Power BI.

## Dataset
Superstore Sales Dataset

## Tool Used
- Microsoft Power BI Desktop

## Dashboard Pages
### 1. Sales Overview
- Total Sales
- Total Profit
- Total Quantity
- Sales by Category
- Sales by Region
- Sales by Segment
- Sales by Month
- Profit analysis

### 2. Detailed Analysis
- Profit by Region
- Profit by Segment
- Profit by Sub-Category
- Quantity by Sub-Category
- Quantity by Segment
- Profit trend over time

## Key Insights
- The dashboard provides an overview of sales, profit and quantity.
- Regional and segment-level performance can be compared easily.
- Category and sub-category analysis helps identify strong and weak performers.
- Time-based analysis shows changes in business performance.

## Deliverables
- Power BI dashboard (.pbix)
- Dashboard screenshots
- Superstore dataset

## Outcome
This project demonstrates data visualization and storytelling using Power BI to convert sales data into meaningful business insights.
